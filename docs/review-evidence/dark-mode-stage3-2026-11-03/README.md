## Browser evidence

`manual-*.jpg` and `sitebuilder-stage3-*` files are actual local in-app browser
observations. CI attachments are generated by the four `dark-mode-*-review` /
`dark-mode-browser-probe` E2E specs. The workflow retains `test-results` and the
HTML report for seven days. Some body attachments exist only in that report's
embedded ZIP. The main review links the CI run and preserves selected JSON here.

`served-head-matrix.json` contains actual Django responses generated from three
historical production writers. The legacy browser spec replays these responses
under synthetic HTTP URLs, preserving CSP and counting intercepted documents.
That replay is separate from the published spec's live disposable Django API
requests. No production request, account or database is used.

`ci-f282fc7/` preserves the first run, including its invalid raw-background
pixel fixture and Chromium middle-click retry. `ci-8183339/` preserves the final
run: Chromium 129 passed; Firefox 128 passed and one failed twice on the real
first-device request. The failure is deliberately reported, not hidden by
changing the expected palette. Both engines passed the corrected dark-frame
pixel check. Published evidence filenames include the test's source line so
the four tests' identically named attachments cannot overwrite one another.
