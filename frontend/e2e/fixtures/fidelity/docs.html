Getting started

Tidepool keeps a folder in step with a storage bucket, sending only what changed.

Install

brew install tidepool
curl -fsSL https://example.com/install.sh | sh
winget install Tidepool.CLI

Configuration

Run tidepool init in the folder you want to sync. It writes a tidepool.toml file with these settings:

SettingDefaultWhat it does
bucketnoneWhere files are sent
interval30sHow often the folder is checked
deletefalseRemove remote files deleted locally

Careful: turning on delete removes files from the bucket for good.

Commands

  • tidepool sync sends what changed once and exits.
  • tidepool watch keeps running and syncs on every change.
  • tidepool status lists files waiting to be sent.
